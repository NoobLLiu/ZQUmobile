## 一、项目是什么

**「掌上砚园」**——肇庆学院（ZQU）的 Android 校园助手，Flutter 开发。

核心功能就两件事：

1. **把教务系统的课表抓下来，用漂亮的周视图网格展示**（这是整个项目的重点，绝大部分迭代都花在这里）
2. **快捷访问教务系统网页**（纯登录，不导入）

为什么要做：学校官方没有好用的课表 App，而现有第三方方案（拾光课表）需要用户自己配置适配脚本。本项目把肇庆学院的适配脚本内置进来，做到「登录 → 一键导入 → 直接看课表」。

**重要：本项目没有任何后端服务**。所有数据在设备本地，不经过第三方服务器。这条是硬约束，不要引入服务端。

> 2026-10-31 变更：按用户要求改为「账号密码验证码全部代填」，学号与两套密码
> （WebVPN / 教务系统）保存在本机 `shared_preferences`，只用于登录时代填，不上传。
> 原「不存账号密码」的约定就此作废，不要再按旧约定删掉密码字段。
>
> 同日续：图形验证码也纳入代填，但**不是硬编码/打码平台，而是本机离线识别**。
> 识别需要真实样本（该验证码非标准字体，实测与 10 种系统字体的最佳相关仅
> 0.54~0.60，合成训练不可行），所以加了「我的 → 验证码训练」逐张手输攒样本，
> 另外每次登录成功会自动回流一张。**识别没把握就退回手动输入**，
> 一轮登录最多自动尝试 2 次，绝不连续瞎猜（避免账号被锁）。

## 四、核心链路：课表是怎么抓下来的

这是全项目最需要理解的部分。

### 4.1 为什么用 WebView

教务系统（URP 系，Struts2，`xxx!yyy.action`）没有开放 API，登录有图形验证码、还有 SSO 跳转。**唯一现实的做法**是内嵌 WebView 让用户自己登录，登录后再用同一会话（cookie）在页面内 `fetch` 接口。

这是照抄「拾光课表」的方案，也是本项目能成立的基础。

### 4.2 数据来源

```
GET xsgrkbcx!getKbRq.action?xnxqdm=<学期>&zc=<周次>&xsdm=
```

关键点：**`zc`（周次）传空表示不限周次，一次返回整学期所有排课记录**，每条记录自带 `zc` 字段标明该课上课周次。所以不需要逐周请求，也不需要解析 HTML 表格。

另一个接口 `xsgrkbcx!getXsgrbkList.action` 只用来取学期下拉框 `#xnxqdm` 的选项。

### 4.3 脚本分成两层（重要，别搞混）

| 文件 | 作用 | 能否修改 |
|---|---|---|
| `assets/js/zqu_upstream.js` | 拾光 `shiguang_warehouse/resources/ZQU/zqu_01.js` **原文** | ❌ 不要改业务逻辑，改了就失去与上游同步的意义 |
| `assets/js/shiguang_bridge_shim.js` | 把官方脚本用到的 `window.shiguangBridge` / `shiguangBridgePromise` 映射到本 App 的 `window.zsyBridge` | ✅ 这是我们的胶水层 |

注入时由 `JwglAdapterRepository.compose(shim, upstream)` 拼成：

```js
<shim>
(function () {
<upstream 原文>
})();
```

**为什么要包 IIFE**：上游脚本顶层有 `const KB_LIST_PAGE = ...` 等声明，用户重复点「执行导入」时第二次注入会抛 `Identifier 'KB_LIST_PAGE' has already been declared`。

### 4.4 双向桥接（v1.1.0 起）

```
JS → Flutter（单向通知）：window.zsyBridge.postMessage(JSON)
     type: progress / courses / config / slots / done / result(ok:false)

Flutter → JS（回填用户输入）：window.__zsyResolve(requestId, value)
     JS 先 post {type:'request', requestId, requestType, payload}，
     Flutter 弹窗拿到结果后调 __zsyResolve 回填，官方脚本的 await 才继续。
     目前 requestType：term（选学期）、startDate（确认开学日期）
```

### 4.5 官方脚本的回传顺序（决定了落库方式）

```
courses → config → slots → done
```

`JwglLoginPage` 逐段累积到 `_accCourses / _accTotalWeeks / _accStartDate / _accSlots`，**收到 `done` 才组装 Timetable 落库**。

⚠️ 顺序有个陷阱：官方脚本是「先确认开学日期，再保存课程」，如果 `showPrompt` 返回 `null`，它会判定用户取消并丢弃已抓到的课程。所以 shim 里取不到日期时返回**空串**而不是 null。

### 4.6 学期名从哪来（踩过的坑）

- ❌ 不能用 WebView 网页标题——那是「教学管理系统」
- ❌ 不能信官方脚本给的 `defaultIndex`——教务下拉框当前值取不到时它会退回 **index 0，也就是最老的学期**，导致导错学期、周次全错位
- ✅ 正确做法：双向弹窗里，用户在「选择学期」列表选中的那一项写入 `_accTermName`；拿不到时退回个人信息里的学期

## 七、踩坑记录（按严重程度排序，都是真实踩过的）

### 1. 本机 Gradle 一定卡死 → 永不本机编译

走代理访问 `dl.google.com` 时隧道能建立（CONNECT 200），但之后 **0 B/s 挂死**，实测 26 分钟毫无产出。直连反而 0.33 秒完成。

**结论：本项目一律走 CI 出包。** 不要试图在本机 `flutter build apk` 修「小问题」，那是无底洞。

### 2. CI 必须用 windows-latest，不能用 ubuntu

Flutter 新版模板会生成 `:jni` 模块（native_assets），AGP 需要 CMake 3.22.1。

- ubuntu runner 的 Android SDK **没预装 CMake**，AGP 自行下载时 `dl.google.com` 报 **Connection refused**，任务 `:jni:configureCMakeRelWithDebInfo[arm64-v8a]` 失败
- 试过 `sdkmanager cmake;3.22.1`（整批传参时若含仓库不存在的 `ninja`，会**整批中止**，cmake 也一起没装）、`apt install cmake`，全部无效
- windows-latest 的 Android SDK 镜像**已预装 CMake**，AGP 直接找到，不需要任何安装步骤

前 4 轮 CI 全栽在这里，第 5 轮换 windows 才成功。

### 3. 不要在 CI 里配国内 Maven 镜像

runner 在境外，阿里云镜像反而慢/超时。`settings.gradle.kts` / `build.gradle.kts` / `gradle.properties` 应保持 **Flutter 模板默认**。之前为本地绕代理加的镜像和 `proxyHost=127.0.0.1:1` 已全部撤除，不要再加回去。

### 4. WebView 桥接两端命名必须成对

初版 Dart 注册 `addJavaScriptChannel('zsyBridge')`，而注入脚本调用 `window.flutterBridge.postMessage`——名字不匹配，脚本结果永远传不回来，且 `post()` 失败是**静默**的。

表现：用户点「执行导入」毫无反应，连报错都没有。

**教训：桥接调用绝不能静默失败**，现在 shim 里通道缺失会 `console.log` 兜底。

### 5. Dart 字符串插值陷阱

```dart
'第$course.day 周'   // ❌ 输出：第Instance of 'Course'.day 周
'第${course.day} 周' // ✅
```

只写 `$course.day` 时 Dart 只插值 `$course`。这个 bug 曾被用户截图指出来。

### 6. versionCode 不动 = 用户以为没更新

见第二节。每次改版必须递增 `+N`。

### 7. 产物文件名必须 ASCII

中文文件名经 `gh release upload` 上传会被吞（`掌上砚园-1.0.2.apk` → `-1.0.2.apk`）。

### 8. 网格列宽不能强制最小值

曾写 `math.max(56.0, availW / displayDays)`，7 列时总宽 40+56×7=432 > 屏幕 400，**周日被裁掉一半**。现在精确等分（最小仅 38 兜底）。

### 9. `ProfileRepository` 不要加静态缓存

加了缓存后，改完个人信息再读会拿到旧值（也曾让测试互相污染）。每次直接读 SharedPreferences。

### 10. 测试断言只能选首屏可见的文本

「我的」页是 ListView，靠下的项未渲染时会 `findsNothing`。要么滚动，要么只断言靠上的项。

## 八、给接手者的建议（按优先级）

1. **真机联调优先验证这三件事**，这是最容易出问题的地方：
   - 未购校园网时，从 `webvpn-free.zqu.edu.cn` 登录后能否进入教务系统功能页
   - 自动填学号在 WebVPN 登录页是否生效（深信服字段多为 `#svpn_name`）
   - 导入时弹窗选学期 → 选日期 → 冲突择一，全流程是否顺畅

2. **不要随意改动 `assets/js/zqu_upstream.js`**。它是上游原文，改了就和上游失去同步。要改行为请改 shim。

3. **改 `schedule_grid.dart` 前先读 `grid_style.dart`**，尺寸全部对齐拾光，动一个数字会牵动排版。

4. 如果用户报「课表空白」，先看课表页标题下的「共 N 门课」：
   - 有 N 门但格子空 → 渲染/周次匹配问题
   - 共 0 门 → 落库问题
   - 顶部出现「第 X 周没有课程排课」→ 开学日期偏了

5. 想加新功能（成绩/空教室）时，接口同样是 WebView 会话内 `fetch`，可参照现有适配脚本的取数方式。注意用户**明确讨厌占位按钮**，做不出功能就先别放按钮。

## 十、本会话对话历史摘要（按时间顺序）

记录用户提了什么、我怎么解决的，便于理解每个设计的由来。

1. **「继续未完成的工作」** — 承接上一会话（本地编译 APK 卡住）。重新跑构建，20 分钟无产出，用户问下载速度。
